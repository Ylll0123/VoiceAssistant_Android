# HardlySeek · 本地智能语音助手（C3 课题）

Android 课程大作业 —— C 档「挑战级」课题 C3：本地智能语音助手。
应用在桌面上显示为 **HardlySeek**。

## 项目简介

通过语音识别 + 规则引擎 + 按需联网 + 云端大模型 + TTS 实现一个可对话、
可执行本地功能（含**真正会响的定时提醒**）的语音助手，
并配套一个独立的通知提醒中心伴生模块。

- **主课题**：C3 本地智能语音助手（语音识别 + 规则引擎 + TTS，多功能集成）
- **伴生模块**：P3 通知提醒中心（AlarmManager 定时 + 通知直接操作）

设计上以 **离线优先** 为准绳：不联网、不配云端时，助手依然完全可用；
联网与云端只是让答案更实时、更会说话的**增强项**。

## 当前功能

### 一、语音交互

- ✅ 语音输入：系统 `SpeechRecognizer`（中文，支持边说边出部分结果）
- ✅ 语音播报：系统 `TextToSpeech`，播报结束回调驱动连续对话
- ✅ 连续对话模式：一轮回答播完自动重新听（顶栏循环图标可开关）
- ✅ 文字输入兜底：识别服务不可用时仍可对话
- ✅ 权限与生命周期：录音权限动态申请，退后台自动停止识别与播报

### 二、调度（核心）

一句话先过**模糊容错引擎**：属于提醒域（新建 / 查看 / 改时间 / 取消）的
就直接被对话管理器接走，0 请求 0 token，用模板回话；其余问题再按下面的顺序
**短路执行**，命中就返回，绝不往下多走一步：

```
① 本机工具   提醒 / 计时 / 音量 / 时间 / 计算 / 复读 → 0 请求 0 token
② 本地问答   规则 / 闲聊 / 记忆 / 知识库          → 0 请求 0 token
③ 按需联网   天气 / 百科（公开免费数据源）        → 0 token
④ 云端大模型 唯一花钱的一步
⑤ 兜底       上面全失败 → 用本地那条答案，绝不空屏
```

- ✅ **串行执行、只上屏一次**：整条链在子线程跑完只拿回一个结果，
  根治了「本地先上屏、云端回来再顶掉」的抢答问题
- ✅ **可见的思考过程**：淡色等宽小字逐行显示「正在理解…· 拆出主问题…
  · 联网查天气…」，答案出现即清除（设置页可关）
- ✅ **路线决策可单测**：`RoutePlanner` 是纯函数，四个接口都能用假实现替换，
  于是可以直接断言「本地能答时，联网和云端一次都没被调用」

### 三、对话能力（规则引擎）

- ✅ 意图注册表结构：内置 16 条规则，按优先级依次匹配
- ✅ **听得清 · 多候选识别**：向系统要 5 条识别候选，逐条尝试理解，
  首选被听错（「打开日立」）时后面的「打开日历」还能救回来
- ✅ **听得清 · 同义词归一**：段子→笑话、礼拜→星期、钢镚→硬币、明儿→明天…
  改词表就能扩说法，不用改规则代码
- ✅ **听得清 · 纠错说法**：「不对，我是说讲个笑话」直接按后半句重新理解
- ✅ **听得清 · 没听懂会反问**：找不到匹配时用相似度找最接近的示例，
  问「你是不是想问『现在几点了』？」，回答「是 / 不是」即可继续
- ✅ **听得懂 · 本地语义理解**（`QueryUnderstanding`）：长句拆主子句、
  指代消解（「它怎么样」→「上海怎么样」）、归纳成简要问题再问云端
- ✅ **听得懂 · 多轮上下文**：`DialogContext` 记住上一轮意图与槽位，3 分钟内有效
  - 「帮我算 25 乘以 4」→「再加 5」→ 基于上一次结果接着算
  - 「纽约现在几点」→「那东京呢」→ 只换城市（同一套规则重讲，不复制逻辑）
  - 「10 公里是多少英里」→「那 20 公里呢」→ 沿用换算方向
  - 「明天天气怎么样」→「那后天呢」；「讲个笑话」→「再来一个」
  - 猜数字游戏：目标值存在槽位里，逐轮提示大了/小了

### 四、本机工具（0 请求）

- ✅ **定时提醒（会真的响）**：「提醒我明天八点交报告」→ AlarmManager 精确定时 →
  到点弹通知，通知上可直接「10 分钟后再提醒」或「知道了」
  - 时间解析：相对时长（10 分钟后 / 半小时 / 两小时）、今天明天后天、
    具体日期（11 月 10 号）、时段（下午 / 晚上 / 中午）、半点 / 一刻
  - 说的时间已经过了会**顺延一天**，不会出现「设完立刻响」
  - 提醒存在本地，重启手机 / 覆盖安装后自动重排闹钟（AlarmManager 的登记会丢）
  - 没说时间的提醒不假装能响，会明确告诉你差个时间
- ✅ **计时器 / 倒计时**：「计时五分钟」「定个十分钟的闹钟」，到点弹通知，
  说「取消计时」可以中途停掉
- ✅ **手电筒**：「打开手电筒」「关掉手电筒」，直接控制闪光灯
- ✅ **查电量**：「手机还有多少电」，顺带说一句在不在充电
- ✅ **打开应用**：「打开微信」「打开相机」「打开设置」，按名字拉起常用应用；
  没装就如实说找不到，不会偷偷开浏览器
- ✅ **复读朗读**：「说出我爱中国」「帮我朗读好好学习」——后面的字原样念出来，
  一个字都不改、也不上网查；正常提问（「说个笑话」）不会被它抢走
- ✅ 提醒清单：增删改查、按序号删除、全部清空
- ✅ 音量 / 静音 / 取消静音 / 调大调小：直接改系统音量
- ✅ 停止播报：说「别说了」立刻闭嘴
- ✅ 中文数字算术：支持「帮我算一下十二乘以八」= 96
- ✅ 教学保护：「记住：提醒我喝水」是教学，不会被当成真的去建提醒

### 五、联网与云端

- ✅ 按需联网：只有本地答不好、且确实是事实类问题才联网
  - 天气：Open-Meteo（有城市）/ wttr.in（按 IP 定位），支持明天、后天
  - 百科：必应搜索 RSS，免 Key
  - 全部失败 → 回落本地答案，话术是「这次没查到」而不是「我不联网」
  - 权限：`INTERNET` + `ACCESS_NETWORK_STATE`；没网时网络层直接失败回落，
    不让用户干等超时
- ✅ 云端大模型（AI 大脑）：任意 OpenAI `/chat/completions` 兼容接口
  - **默认就接智谱 GLM-4-Flash-250414**（官方免费、128K 上下文）：装完不用注册、
    不用配置，问一句就能用
  - 内置一把共享 Key，编译期从 `local.properties` 注入 `BuildConfig`，
    **源码仓库里没有这串 Key**，只有打出来的 APK 带着它
  - 想换成自己的：设置页最底部「AI 模型」一行点进去改，改过之后以本地保存的为准
  - 也可以换任意 OpenAI 兼容服务：DeepSeek、火山方舟（豆包）、通义、Kimi、硅基流动…
  - 「本地优先」（答不好才问）与「AI 优先」（都问）两种模式，默认本地优先
  - 温度用 OpenAI 默认值 1（思考型模型硬性要求，填 0.7 会被 400 拒绝）
- ✅ 省 token 组合拳：
  - 云端只发**归纳后的简要问题**（23 字 → 7 字）
  - 历史按需带（只有存在指代或明确追问时才带），且每轮截到 40 字
  - 会话内 LRU 缓存（换服务商 / 模型时清空）
  - system 提示瘦身到约 50 字

### 六、本地学习（越聊越会）

- ✅ `memory` 包 + 底部「记忆」页
  - 本地 SQLite 记忆库（零新增依赖），预置 26 条常识对话，教一条长一条
  - 三种教法：`记住：下班了 = 早点回家` / `当我说…的时候你就说…` / 答不上时说「我教你」
  - 检索三层证据：完全相同 → 包含关系 → 编辑距离 + 字符二元组 + 关键词覆盖率
  - 记忆页可视化：来源（内置 / 我教的）、删除、对话框教学
  - 内置规则优先于记忆，教错的内容可以在记忆页删掉
- ✅ 云端的好答案会回灌给本地小模型（学的是「人怎么问」，所以用原话）

### 七、界面：三项导航 + 多语言 + 账号

- ✅ 底部导航三页：**对话** / **功能** / **设置**
  - 对话页：消息气泡列表（用户/助手）、状态栏、麦克风与发送；
    输入框**上方**常驻「教学」入口（教一句 / 看记忆 / 补答没答上来的）
  - 功能页：一行一行按分类列出，点开一行才展开该类技能，再点一条才展开示例说法
    （两级折叠，一屏看得到全部能力又不拥挤）；「我的记忆」是这里的二级页，
    带返回箭头并接管系统返回键
  - 设置页只留必要项：回答方式（精简 / 详细）、界面语言、清空对话、账号、恢复默认设置。
    **不摆「是否接入大模型」的开关**——默认就接着 GLM-4-Flash-250414，
    只在「关于」里留一行模型名，点开才填 Key / 换服务商 / 测试连接
- ✅ **四语言界面**：中文 / English / 日本語 / 한국어，`values-en / -ja / -ko` 全套翻译
  （连功能页 30 条技能的标题和说明也逐条翻译；示例说法保持中文并在页尾说明原因）。
  语言由 `LocaleHelper` 自己控制（重写 `attachBaseContext` + 启动时按存盘值套用），
  不依赖系统语言，也不依赖 Android 13 的「按应用设置语言」——低版本一样能切
- ✅ **登录注册**：本地账号，密码用 PBKDF2 加盐哈希（`data/Passwords`，有 7 条单测），
  登录 / 注册切换，也可直接以游客身份进入；外部 `--es query` 入口不受门禁影响
- ✅ **点气泡改 / 删**：点自己的气泡弹出「修改 / 删除」；删除会连带这条的助手回答，
  不留没头没尾的半截对话；改完落盘，重启后是新内容
- ✅ 对话状态由 `ChatSession` 持有，切页面不丢消息
- ✅ 安全区适配：状态栏 / 导航栏留白统一交给根布局，键盘弹起时隐藏底部导航

### 八、装完自清理安装包 + 外部调用入口

- ✅ **装完自动清理安装包**（每个版本只做一次，不弹自建确认框）：
  1. 本应用能索引到的下载项 → 直接 `delete()`，用户完全无感；
  2. 索引不到的（浏览器 / adb push 进来的）→ 直接发 `MediaStore.createDeleteRequest`，
     系统弹一次「允许删除？」，用户点一下即可。
  如实说明：Android 从 10 起**不允许**一个应用静默删除别的应用写的文件，
  这是分区存储的安全模型，不是权限没申请够——系统那一下确认省不掉，
  但应用自己不再多问一句。
- ✅ **外部调用入口**：`adb shell am start -n com.example.voiceassistant/.ui.VoiceAssistantActivity --es query "提醒我交作业"`
  （或任何 App 用同样的 extra），配合 `launchMode=singleTop`，第二句会回到同一实例，
  多轮上下文不会断

## 分层与目录结构

整体按「**事件总线 + 四大模块**」组织。一句话的旅程：

```
话筒 ──▶ ① 语音链路 ──RawText──▶ ② 模糊容错引擎 ──IntentRecognized──▶ ③ 对话管理
                                                                          │
                                      ④ 提醒中心 ◀── 增删改查 ─────────────┘
                                          │
                                     ReminderFired ──▶ 界面 / TTS
```

| 模块 | 职责 | 关键文件 |
| --- | --- | --- |
| 事件总线 | 同步分发、按类型订阅、owner 批量注销、异常隔离 | `bus/EventBus`、`bus/AssistantBus` |
| ① 语音链路 | ASR / TTS / 连续对话（系统能力，见 `service/`） | `AsrManager`、`TtsManager` |
| ② 模糊容错 | 归一化 → 纠错 → 规则模板 → 编辑距离 → **置信度** | `fuzzy/TextNormalizer`、`fuzzy/FuzzyEngine`、`fuzzy/Levenshtein` |
| ③ 对话管理 | 槽位补全、指代消解、会话超时、模板化回复 | `dialog/DialogueManager`、`dialog/DialogueSession` |
| ④ 提醒中心 | 增删改查、重复规则、状态机、调度与通知 | `reminder/ReminderCenter`、`ReminderDb`、`ReminderAlarm` |

模块之间只通过事件总线递消息：语音链路不知道提醒怎么存，
提醒中心不知道这句话是谁说的、界面上长什么样——换掉任何一块都不影响其它三块。

### 模糊容错的四层策略

| 层 | 手段 | 解决什么 | 例 |
| --- | --- | --- | --- |
| ① | 归一化 + 词表纠错 | 全角、语气词、同音字 | 「明天**山**点提醒我」→ 三点 |
| ② | 规则模板 + 槽位 | 「提醒我 X」「改到 X」「取消 X」 | 抽 `intent` / `time` / `content` |
| ③ | 编辑距离 | 单字错、短指令变体 | 「取消提箱」→ `cancel_remind` |
| ④ | 置信度闸门 | 拦下非指令 | 「提醒有什么意义」→ 不建提醒 |

置信度 ≥ 0.8 直接执行；0.55~0.8 追问确认；< 0.55 当没听懂交给问答链路。
**宁可多问一句，也不猜着去建一条错提醒。**

### 多轮上下文

```
用户：提醒我交作业          → 意图 set_remind，但 time 空 → 反问「几点？」
用户：三点                  → 补全槽位 → 建提醒，记住 ref_remind_id
用户：改成四点              → 意图 update_remind，目标由 ref_remind_id 补全
```

会话上下文只在内存、120 秒过期：过期后「改成四点」不再瞎猜指代，
而是反问「要改哪一条」。长期数据（提醒清单）在 SQLite，两者不混。

```
│   ├── ReminderRepeat.kt            下一次触发时刻（按日历加，含夏令时）
│   ├── ReminderAlarm.kt             精确闹钟 + 通知 + Action
│   ├── ReminderReceiver / BootReceiver
│   └── Reminders.kt                 安装入口（建渠道 / 迁移旧数据 / 重排闹钟）
├── installer/                   装完自动清理安装包（分区存储下的合规删法）
│   └── ApkCleaner.kt
├── network/                     网络层
│   └── Http.kt / SearchApi.kt / LlmRequest.kt / NetworkState.kt
├── service/                     语音服务层
│   └── AsrManager / TtsManager / TtsTiming（播报兜底）/ AudioController / DeviceController
├── assistant/                   规则与知识（纯逻辑，可直接单测）
│   └── AssistantEngine / AssistantRules / DialogLogic / KnowledgeBase
│       FuzzyMatcher / QueryUnderstanding / NgramModel / ChineseNumber …
├── memory/                      记忆库（SQLite + 检索 + 内置语料）
└── data/                        会话、设置与账号
    ├── ChatSession / ChatHistoryStore（对话落盘）/ ChatMessage
    ├── AppSettings（设置 + 语言 + 云端配置）
    ├── AccountStore / Passwords（本地账号，PBKDF2 加盐）
    └── LocaleHelper（语言上下文）/ JsonLite
```

层与层之间靠 `core/Sources.kt` 里的四个接口 + `reminder/ReminderPort` 解耦，
所以换大模型、换搜索源、换提醒存储、加新工具都不用碰调度核心。
