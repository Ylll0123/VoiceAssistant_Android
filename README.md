# HardlySeek · 本地智能语音助手（C3 课题）

Android 课程大作业 —— C 档「挑战级」课题 C3：本地智能语音助手。
应用在桌面上显示为 **HardlySeek**。

## 项目简介

通过语音识别 + 规则引擎 + 按需联网 + 云端大模型 + TTS 实现一个可对话、
可执行本地功能（含**真正会响的定时提醒**）的语音助手，
并配套一个独立的通知提醒中心伴生模块。

- **主课题**：C3 本地智能语音助手（语音识别 + 规则引擎 + TTS，多功能集成）
- **伴生模块**：P3 通知提醒中心（AlarmManager 定时 + 通知直接操作）

设计上以 **离线优先** 为准绳：不联网、不配云端时，助手依然完全可用；
联网与云端只是让答案更实时、更会说话的**增强项**。

## 当前功能

### 一、语音交互

- ✅ 语音输入：系统 `SpeechRecognizer`（中文，支持边说边出部分结果）
- ✅ 语音播报：系统 `TextToSpeech`，播报结束回调驱动连续对话
- ✅ 连续对话模式：一轮回答播完自动重新听（顶栏循环图标可开关）
- ✅ 文字输入兜底：识别服务不可用时仍可对话
- ✅ 权限与生命周期：录音权限动态申请，退后台自动停止识别与播报

### 二、调度（核心）

一句话进来后按固定顺序**短路执行**，命中就返回，绝不往下多走一步：

```
① 本机工具   提醒 / 计时 / 音量 / 时间 / 计算 / 复读 → 0 请求 0 token
② 本地问答   规则 / 闲聊 / 记忆 / 知识库          → 0 请求 0 token
③ 按需联网   天气 / 百科（公开免费数据源）        → 0 token
④ 云端大模型 唯一花钱的一步
⑤ 兜底       上面全失败 → 用本地那条答案，绝不空屏
```

- ✅ **串行执行、只上屏一次**：整条链在子线程跑完只拿回一个结果，
  根治了「本地先上屏、云端回来再顶掉」的抢答问题
- ✅ **可见的思考过程**：淡色等宽小字逐行显示「正在理解…· 拆出主问题…
  · 联网查天气…」，答案出现即清除（设置页可关）
- ✅ **路线决策可单测**：`RoutePlanner` 是纯函数，四个接口都能用假实现替换，
  于是可以直接断言「本地能答时，联网和云端一次都没被调用」

### 三、对话能力（规则引擎）

- ✅ 意图注册表结构：内置 16 条规则，按优先级依次匹配
- ✅ **听得清 · 多候选识别**：向系统要 5 条识别候选，逐条尝试理解，
  首选被听错（「打开日立」）时后面的「打开日历」还能救回来
- ✅ **听得清 · 同义词归一**：段子→笑话、礼拜→星期、钢镚→硬币、明儿→明天…
  改词表就能扩说法，不用改规则代码
- ✅ **听得清 · 纠错说法**：「不对，我是说讲个笑话」直接按后半句重新理解
- ✅ **听得清 · 没听懂会反问**：找不到匹配时用相似度找最接近的示例，
  问「你是不是想问『现在几点了』？」，回答「是 / 不是」即可继续
- ✅ **听得懂 · 本地语义理解**（`QueryUnderstanding`）：长句拆主子句、
  指代消解（「它怎么样」→「上海怎么样」）、归纳成简要问题再问云端
- ✅ **听得懂 · 多轮上下文**：`DialogContext` 记住上一轮意图与槽位，3 分钟内有效
  - 「帮我算 25 乘以 4」→「再加 5」→ 基于上一次结果接着算
  - 「纽约现在几点」→「那东京呢」→ 只换城市（同一套规则重讲，不复制逻辑）
  - 「10 公里是多少英里」→「那 20 公里呢」→ 沿用换算方向
  - 「明天天气怎么样」→「那后天呢」；「讲个笑话」→「再来一个」
  - 猜数字游戏：目标值存在槽位里，逐轮提示大了/小了

### 四、本机工具（0 请求）

- ✅ **定时提醒（会真的响）**：「提醒我明天八点交报告」→ AlarmManager 精确定时 →
  到点弹通知，通知上可直接「10 分钟后再提醒」或「知道了」
  - 时间解析：相对时长（10 分钟后 / 半小时 / 两小时）、今天明天后天、
    具体日期（11 月 10 号）、时段（下午 / 晚上 / 中午）、半点 / 一刻
  - 说的时间已经过了会**顺延一天**，不会出现「设完立刻响」
  - 提醒存在本地，重启手机 / 覆盖安装后自动重排闹钟（AlarmManager 的登记会丢）
  - 没说时间的提醒不假装能响，会明确告诉你差个时间
- ✅ **计时器 / 倒计时**：「计时五分钟」「定个十分钟的闹钟」，到点弹通知，
  说「取消计时」可以中途停掉
- ✅ **手电筒**：「打开手电筒」「关掉手电筒」，直接控制闪光灯
- ✅ **查电量**：「手机还有多少电」，顺带说一句在不在充电
- ✅ **打开应用**：「打开微信」「打开相机」「打开设置」，按名字拉起常用应用；
  没装就如实说找不到，不会偷偷开浏览器
- ✅ **复读朗读**：「说出我爱中国」「帮我朗读好好学习」——后面的字原样念出来，
  一个字都不改、也不上网查；正常提问（「说个笑话」）不会被它抢走
- ✅ 提醒清单：增删改查、按序号删除、全部清空
- ✅ 音量 / 静音 / 取消静音 / 调大调小：直接改系统音量
- ✅ 停止播报：说「别说了」立刻闭嘴
- ✅ 中文数字算术：支持「帮我算一下十二乘以八」= 96
- ✅ 教学保护：「记住：提醒我喝水」是教学，不会被当成真的去建提醒

### 五、联网与云端

- ✅ 按需联网：只有本地答不好、且确实是事实类问题才联网
  - 天气：Open-Meteo（有城市）/ wttr.in（按 IP 定位），支持明天、后天
  - 百科：必应搜索 RSS，免 Key
  - 全部失败 → 回落本地答案，话术是「这次没查到」而不是「我不联网」
  - 权限：`INTERNET` + `ACCESS_NETWORK_STATE`；没网时网络层直接失败回落，
    不让用户干等超时
- ✅ 云端大模型（AI 大脑）：任意 OpenAI `/chat/completions` 兼容接口
  - 内置预设：DeepSeek、火山方舟（豆包）、通义、智谱、Kimi、 siliconflow…
  - 「本地优先」（答不好才问）与「AI 优先」（都问）两种模式
  - 温度用 OpenAI 默认值 1（思考型模型硬性要求，填 0.7 会被 400 拒绝）
- ✅ 省 token 组合拳：
  - 云端只发**归纳后的简要问题**（23 字 → 7 字）
  - 历史按需带（只有存在指代或明确追问时才带），且每轮截到 40 字
  - 会话内 LRU 缓存（换服务商 / 模型时清空）
  - system 提示瘦身到约 50 字

### 六、本地学习（越聊越会）

- ✅ `memory` 包 + 底部「记忆」页
  - 本地 SQLite 记忆库（零新增依赖），预置 26 条常识对话，教一条长一条
  - 三种教法：`记住：下班了 = 早点回家` / `当我说…的时候你就说…` / 答不上时说「我教你」
  - 检索三层证据：完全相同 → 包含关系 → 编辑距离 + 字符二元组 + 关键词覆盖率
  - 记忆页可视化：来源（内置 / 我教的）、删除、对话框教学
  - 内置规则优先于记忆，教错的内容可以在记忆页删掉
- ✅ 云端的好答案会回灌给本地小模型（学的是「人怎么问」，所以用原话）

### 七、多页面

- ✅ 底部导航四页：**对话** / **技能** / **记忆** / **设置**
  - 对话页：消息气泡列表（用户/助手）、状态栏、麦克风与发送；
    顶栏另有一个「技能」按钮，底部导航万一被系统栏遮挡也能进技能页
  - 技能页：按分类展示全部能力 + 可点击的示例说法，点击后自动跳回对话页执行
  - 设置页：语音播报、连续对话、显示理解过程、本地小模型、联网查询开关，
    云端配置与测试连接，上下文调试信息，清空上下文与对话
- ✅ 对话状态由 `ChatSession` 持有，切页面不丢消息
- ✅ 安全区适配：状态栏 / 导航栏留白统一交给根布局，键盘弹起时隐藏底部导航

## 技术栈

| 分类 | 选型 |
| --- | --- |
| 语言 | Kotlin |
| 架构 | 单 Activity + 四 Fragment，按职责分层（ui / core / handler / tool / network / service / assistant / memory / data） |
| 本地存储 | SQLite（自建极简封装，零新增依赖）+ SharedPreferences（提醒清单 / 最近 40 条对话） |
| 后台任务 | AlarmManager 精确闹钟（`setExactAndAllowWhileIdle` / `setAlarmClock`）+ 通知 Action，开机自动重排 |
| 语音 | Android `SpeechRecognizer` / `TextToSpeech` |
| 联网 | `HttpURLConnection` + 项目自带极简 JSON 解析（`JsonLite`） |
| 测试 | JUnit4（379 个单测，覆盖调度顺序、路线决策、语义理解、规则引擎、工具、提醒解析、对话落盘、联网、云端、记忆） |
| 构建 | Gradle 9.5 + AGP 9.3，minSdk 28 / targetSdk 37 |

## 分层与目录结构

```
app/src/main/java/com/example/voiceassistant/
├── ui/                          界面层：只做接线，不写业务判断
│   ├── VoiceAssistantActivity.kt    应用外壳 + 语音入口
│   ├── ChatFragment.kt / SkillsFragment.kt
│   ├── MemoryFragment.kt / SettingsFragment.kt
│   └── ChatAdapter.kt / MemoryAdapter.kt
├── core/                        调度核心：决定「这一轮该问谁」
│   ├── AssistantRouter.kt           串行调度总入口（plan / run / processAsync）
│   ├── RoutePlanner.kt              路线决策（纯函数：本地/联网/云端）
│   ├── HistoryManager.kt            历史落盘 + 给云端准备上下文
│   ├── TextCleaner.kt               文本清洗（归一化 / 截断 / 缓存键）
│   └── Sources.kt                   四个接口契约（core 只认接口不认实现）
├── handler/                     处理器层：真正干活的三条路
│   ├── qa/QaLocalHandler.kt         本地问答（规则/闲聊/记忆/知识库）
│   ├── qa/QaLib.kt                  可编辑问答表（assets/qa_lib.json）
│   ├── web/WebHandler.kt            按需联网
│   └── llm/CloudLlmHandler.kt       云端大模型 + CloudCache
├── tool/                        工具层：本机能力，0 请求
│   └── ToolHandler / ReminderTool / ReminderTime / TimerTool / DeviceTool
│       Volume / Time / Calc / ToolReply
├── reminder/                    伴生模块 P3：通知提醒中心
│   └── Reminders（唯一入口）/ ReminderStore（SharedPreferences 持久化）
│       ReminderAlarm（精确闹钟 + 通知 + Action）/ ReminderReceiver / BootReceiver
├── network/                     网络层
│   └── Http.kt / SearchApi.kt / LlmRequest.kt
├── service/                     语音服务层
│   └── AsrManager / TtsManager / TtsTiming（播报兜底）/ AudioController
├── assistant/                   规则与知识（纯逻辑，可直接单测）
│   └── AssistantEngine / AssistantRules / DialogLogic / KnowledgeBase
│       FuzzyMatcher / QueryUnderstanding / NgramModel / ChineseNumber …
├── memory/                      记忆库（SQLite + 检索 + 内置语料）
└── data/                        会话与设置模型
    └── ChatSession / ChatHistoryStore（对话落盘）/ ChatMessage / AppSettings / JsonLite
```

层与层之间靠 `core/Sources.kt` 里的四个接口解耦，
所以换大模型、换搜索源、加新工具都不用碰 `AssistantRouter`。
